# Task Companion｜本地任务陪跑看板

Task Companion 是一个在本机运行的任务管理与专注陪跑工具。你可以用它整理当天任务、判断优先级、记录专注进度，并把每日行动关联到长期项目。

任务数据默认保存在你的电脑上，不需要注册账号。

## 主要功能

- 快速录入任务，补充截止时间、预计用时和任务类型
- 使用四象限整理任务优先级
- 创建长期项目，并记录每天的实际投入
- 启动专注计时，按设定间隔提醒汇报进度
- 在新的一天回顾昨日任务：完成、部分完成或未开始
- 导出本地任务数据作为备份
- 可选配置 AI 服务，用于看板内的陪跑对话和每日复盘习惯分析
- 在 macOS 上使用悬浮陪跑窗口、系统通知和日历记录

## 使用前准备

请先安装：

- [Node.js](https://nodejs.org/) 20 或更高版本
- 一个现代浏览器，例如 Chrome、Safari 或 Edge

在终端中检查 Node.js 是否安装成功：

```bash
node --version
```

如果显示 `v20`、`v22` 或更高版本，就可以继续。

## 第一次启动

### 1. 下载项目

你可以在 GitHub 仓库页面点击绿色的 **Code** 按钮，然后选择 **Download ZIP**。解压后记住项目文件夹的位置。

如果你熟悉 Git，也可以使用：

```bash
git clone https://github.com/joyeen7030/task_Companion.git
cd task_Companion
```

### 2. 启动本地服务

在项目目录中运行：

```bash
node server.mjs
```

终端窗口需要保持打开。关闭终端或停止该命令后，看板也会停止运行。

### 3. 打开任务看板

在浏览器地址栏输入：

```text
http://127.0.0.1:43129/
```

请始终使用这个地址。不要直接双击 `dashboard/index.html`，也不要通过 `file://` 地址打开它，否则页面样式、任务读取和保存功能会失效。

## 新手使用流程

1. 在“快速收集一件事”中输入今天要完成的任务。
2. 确认任务的优先级、预计用时、类型和提醒间隔。
3. 如有长期目标，先创建长期项目，再把每日任务关联到项目。
4. 点击“开始陪跑”，填写这次专注的第一步并开始计时。
5. 收到提醒时记录实际进展；需要休息时可以暂停。
6. 完成后点击专注栏中的“完成”。第二天再次打开看板时，按提示复盘前一天的任务。

每日简报或日历安排也可以直接粘贴进看板。工具会按行拆分内容，再请你逐项确认。

## macOS 可选功能

### 登录后自动启动

在项目目录中运行一次：

```bash
node scripts/install-launch-agent.mjs
```

这会注册本机启动项，让看板服务和悬浮陪跑窗口在登录后自动运行。首次使用系统通知或日历功能时，macOS 可能会请求权限。

取消自动启动：

```bash
node scripts/uninstall-launch-agent.mjs
```

取消启动项不会删除任务数据。

### 日历记录

结束当前专注并将任务标记为完成时，工具会尝试把本次专注写入 Mac 默认日历；你可以点击专注栏的“完成”，也可以勾选正在专注的那项任务。“结束陪跑”或完成未计时的任务不会创建日历事件。

## AI 陪跑设置（可选）

看板可以连接 OpenAI、DeepSeek 或 GLM。点击右上角的“AI 设置”，选择服务商，填写该服务商提供的 API 密钥并选择模型。生成每日复盘时，AI 会结合当天任务状态、近 14 天的进度与复盘记录，以及未完成长期项目，给出简短的习惯观察、记录依据和明天可尝试的一件小改变。

- API 密钥保存在当前 Mac 用户的系统钥匙串中，不写入任务数据文件。
- 使用 AI 对话时，当前任务摘要和对话内容会发送给你选择的服务商处理；生成复盘分析时，相关任务状态、进度记录和未完成项目资料也会发送给该服务商处理。
- 复盘历史只保存三条简短分析结论，不保存详细分析；以后生成新复盘时，AI 会基于仍保留的原始记录重新分析。
- 不配置 AI 服务也可以正常使用任务、项目、复盘和计时功能。

## 数据与隐私

任务、项目、进度记录和日历写入结果保存在：

```text
data/state.json
```

运行日志和 macOS 辅助程序也会生成在 `data/` 目录中。该目录已加入 `.gitignore`，正常情况下不会上传到 GitHub。

你可以点击看板侧边栏“本地数据”旁的下载图标导出备份。需要迁移或重装前，请先保存这份备份。

## 常见问题

### 页面没有样式，或者任务无法保存

检查浏览器地址是否以 `http://127.0.0.1:43129/` 开头。如果地址以 `file://` 开头，请关闭该页面，重新运行 `node server.mjs` 并打开正确地址。

### 浏览器显示无法访问

确认运行 `node server.mjs` 的终端窗口仍然打开，并检查是否有报错。也可以重新执行启动命令。

### 端口 43129 已被占用

这通常表示服务已经在运行。先直接打开 `http://127.0.0.1:43129/`。如果看到 Task Companion 页面，就不需要再次启动。

### 没有收到系统通知

系统通知和悬浮窗口目前只支持 macOS。请确认已经运行自动启动安装脚本，并在 macOS“系统设置 → 通知”中允许 Task Companion 发送通知。

### 日历写入失败

请在 macOS“系统设置 → 隐私与安全性 → 日历”中检查权限，然后在看板中重试写入。

## 停止服务

如果是在终端中手动启动的，在该终端窗口按 `Control + C` 即可停止服务。

本工具只监听本机地址 `127.0.0.1`，不会自动把看板开放到局域网或互联网。
